# ARR May EMNLP Wave Archive

This directory records the ARR May 2026 reviews for the R3L paper with EMNLP as the preferred venue.

Files:

- `openreview_raw.txt`: raw OpenReview page export.
- `reviewer_uCGY.md`, `reviewer_TC9w.md`, `reviewer_vbDZ.md`: original reviewer records, formatted to match the previous rebuttal archive.
- `reviews_summary.md`: consolidated Chinese/English working summary of scores, strengths, weaknesses, and shared concerns.
- `rebuttal_todo.md`: prioritized rebuttal preparation checklist.
- `experiments_todo.md`: detailed experiment plan for rebuttal evidence, including priority, configs, metrics, and expected tables.

The previous ARR wave is archived separately in `../arr_december/`.
