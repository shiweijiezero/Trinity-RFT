# ARR December Wave Archive

This directory archives the first ARR rebuttal wave for the R3L paper.

Files:

- `comments`: raw OpenReview comments export from the first wave.
- `reviewer_iAPy.md`, `reviewer_4viW.md`, `reviewer_XSY9.md`: reviewer records.
- `reviews_summary.md`: consolidated review summary.
- `rebuttal_iAPy.md`, `rebuttal_4viW.md`, `rebuttal_XSY9.md`: Chinese rebuttal drafts.
- `rebuttal_iAPy_en.md`, `rebuttal_4viW_en.md`, `rebuttal_XSY9_en.md`: English rebuttal drafts.

Related current-wave material is kept separately in `../arr_may_emnlp/`.
